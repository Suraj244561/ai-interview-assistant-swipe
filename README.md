**Swipe Internship Assignment - Complete Implementation**

> Smart Technical Interviews for Full-Stack Developers with AI-powered evaluation, real-time timers, and comprehensive candidate management.

## ✅ All Requirements Implemented

### 🎯 Core Features
- ✅ **Two-Tab Interface**: Interviewee (chat) + Interviewer (dashboard) with real-time sync
- ✅ **Resume Upload**: PDF/DOCX support with drag-and-drop functionality  
- ✅ **Field Extraction**: AI-powered extraction of Name, Email, Phone from resumes
- ✅ **Missing Field Collection**: Interactive forms to gather incomplete information
- ✅ **Interview Flow**: 6 questions with progressive difficulty (2 Easy → 2 Medium → 2 Hard)
- ✅ **Smart Timers**: 20s (Easy), 60s (Medium), 120s (Hard) with auto-submit functionality
- ✅ **AI Scoring**: Intelligent evaluation system with detailed feedback (0-100 scale)
- ✅ **Dashboard Management**: Complete candidate listing with search, sort, and detailed views
- ✅ **Data Persistence**: Full localStorage integration with cross-tab synchronization
- ✅ **Session Recovery**: "Welcome Back" modal for interrupted interviews

### 🛠 Technical Features
- ✅ **Responsive Design**: Mobile-first approach with professional UI/UX
- ✅ **Cross-tab Sync**: Real-time updates between multiple browser tabs
- ✅ **Error Handling**: Comprehensive validation and user feedback
- ✅ **File Validation**: Size limits, format checking, and security measures
- ✅ **Modern Architecture**: Clean, maintainable code with component-based design
